# QueryとKeyを照合する

48秒・日本語字幕・無音。Pillow + FFmpegによる独自アニメーション。Manim製ではありません。

## 学習目標

QueryとKeyの各成分を掛けて足すと、照合の点数（内積）が決まる。点数は向きだけでなく長さでも変わり、確率ではないことを確かめる。

## 字幕全文

- 00–06秒：Queryは問い合わせ。Keyは照合するためのベクトルです。
- 06–12秒：実際のQとKは、入力に学習された行列を掛けて作ります。
- 12–18秒：同じ位置の成分を掛け、足す。これが内積です。
- 18–24秒：1 × 2 + 1 × 0 = 2。KAとの照合の点数は2です。
- 24–30秒：KBは2、KCは0。同じQueryでも、Keyごとに点数が変わります。
- 30–36秒：Qを[2, 0]に変えると、点数は4、0、−2になります。
- 36–42秒：内積は向きだけでなく、ベクトルの長さでも変わります。
- 42–48秒：これはまだ確率ではありません。まず、自分で動かしてみましょう。

## 操作との共通初期値

- Q = [1, 1]
- KA = [2, 0]、KB = [0, 2]、KC = [-1, 1]
- 内積 = [2, 2, 0]
- 右向きの例 Q = [2, 0] では、内積 = [4, 0, -2]

説明用に手で設定した数値で、学習済みモデルの出力ではありません。Self-AttentionではQ、Kは入力表現を学習済みの行列で射影して作ります。この単元はスケーリングとsoftmaxの前の内積までを扱います。

出典：[Vaswani et al. (2017), §3.2.1](https://arxiv.org/abs/1706.03762)。
