# Attention Is All You Need 学習体験

概要動画から11の理解単位へ、下にスクロールしながら進む静的な教材です。旧論文ノートの本文はソース内に保管し、旧URLはlearnへ転送します。公開用ルートは /notes/attention-is-all-you-need/learn/ です。実聴・実端末の再生が未確認であることをページ内に明示しています。

## 収録済み

Manimと日本語読み上げによる12本：概要、順番と直接接続、Query/Key、softmax、Value混合、Multi-head、位置符号、因果マスク、学習と生成、計算量、論文の結果、適用範囲。11の理解単位すべてに動画を用意しました。MP4、字幕、ポスター、読み上げ全文、対応する操作を同じ場所にまとめています。

概要動画の下では、QとValue Cを図の上で動かすと、点数・softmaxの重み・混合した出力が同時に変わります。クリック、ドラッグ、キーボード用スライダー、重みを強めるボタンを用意しています。これは固定Keyと2次元Valueを使う説明例で、学習済みモデルではありません。

各単位は「動画 → 予想・操作 → 答え合わせ → 次へ」の順です。目標・導入文・細かな操作手順は、必要なときに開いて読めます。強制移動や自動採点はありません。動画は自動再生せず、再生前に動画本体を読み込みません。

## 構成

- content/：章構成、台本、動画と操作の対応
- src/：計算、操作、共有ヘッダーと支援欄
- media-source/：採用したManim映像の制作コードと検査記録
- public/media/：採用した動画12本と字幕・ポスターのみ
- tools/：静的HTMLの生成と構造検査
- tests/：数値、DOM、動画統合、公開用ルートの検査
- reference/：既存本文の保存用コピー

不採用になった旧映像、重複ZIP、過去の配布物は、このソースにも公開物にも含めません。

## ビルドと検査

このフォルダで npm install を実行すると、DOM検査用の happy-dom 20.0.10 が入ります。利用者に配信するHTMLは依存パッケージを必要としません。

    npm test
    npm run build:local
    npm run build:production

ローカル版は build-local/index.html と隣のmediaフォルダを保持して開きます。公開用は build-production に生成します。リポジトリ最上位の npm run build が公開用ビルドと素材配置を行い、Astroがページルートを出力します。動画はそのルート下の media/ から配信します。

公開用ヘッダーの左上は同じサイトのホーム / に戻ります。著作権方針にも戻れます。別の論文ノートへのリンクは設けません。HOMEからの入口はHOME側のビルドで管理します。
