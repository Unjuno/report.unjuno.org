論文の概要

学習ゴール（本文）：Transformerが入力の離れた位置をどう結びつけるかを、自分の言葉で説明できる。読み終えたら、別の短い系列でも、更新する位置を一つ選び、どの数値を変えると参照の割合が変わるか、どの数値を変えると混ぜる中身だけが変わるかを予測できる。

翻訳を例に、まず「入力文をどう読むか」、次に「入力を手がかりに訳をどう出すか」を分けます。下の概要は動画です。後続の図は仕組みを見比べるため、操作できる図は一つの条件だけを変えて予測を確かめるために使います。

Attentionは、参照する側と参照先を照合し、参照先の情報を混ぜる仕組みです。照合する側の情報をQuery（クエリ、Q）、照合先の情報をKey（キー、K）、混ぜる内容をValue（バリュー、V）と呼びます。

QとKから「どこをどの割合で参照するか」を計算し、その割合でVを混ぜます。これらはモデルの中の数の並びで、単語や質問文そのものではありません。

前提

文を区切り、数の並びで表す

トークンは単語そのものとは限りません。各トークンを順番のある数の組、ベクトルで表します。トークンに対応する数の組を取り出す仕組みが埋め込みです。モデルは学習でこの数値を調整します。

[1, −1] ≠ [−1, 1]

成分の順序には意味があります。成分は負にもなります。下の値は手作りの例で、1番目を「動物らしさ」などと決めた学習済み表現ではありません。

「犬が 人を 追う」と「人が 犬を 追う」は、同じ単語でも順番によって意味が変わります。埋め込みだけでは、同じトークンはどの位置でも同じ表現です。そこで、位置表現という順番を表す数の組を足します。ベクトルの中の成分の順番と、文の中のトークンの順番は別です。

原著では、埋め込みを√d_model倍してから位置表現を成分ごとに足します。d_modelはベクトルの成分数です。ここでは調整済みの説明用表現[1,−1]と、2成分・位置0の位置ベクトル[0,1]を使います。

[1, −1] + [0, 1] = [1, 0]

トークン・埋め込み・位置加算は原論文の要約です。2成分の値と、各成分へ固定の意味を付けない注意は教材の補足です。

逐次処理から、Attentionへ

順番を待つ処理と、直接つながる処理

比較の目的（本文）：RNNを学ぶことが本題ではありません。入力の各位置を更新するとき、どこで前の計算を待つかを、Transformerと同じ条件で比べます。

  1. RNN：各位置は直前の状態を受け取って更新します。基本的な翻訳モデルが最後の状態だけを訳す側に渡す場合、離れた位置の手がかりもそこまで保持する必要があります。
  2. RNN＋Attention：訳す側が入力の各位置の状態を直接参照できるので、最後の状態への詰め込みを減らせます。ただし、RNNで入力の状態を作る順番待ちは残ります。
  3. 畳み込み：各位置の近所を同じ層で並列に処理できます。普通の狭い窓では遠い位置に届くまで層を重ねます。窓幅や間隔を変えれば、その経路は変わります。
  4. Transformerの自己注意：各位置は前の層にある参照可能な位置を直接読みます。同じ層の別の位置の出力を待ちません。全位置の組を照合する場合、系列長を2倍にすると照合の組数は4倍になります。並列性、総計算量、情報の経路は別の比較です。未知の訳を生成する順番待ちは残ります。

比較の根拠は原論文の第2節（先行研究）と第4節（計算量・逐次操作・最長経路）です。各方式の実機での速さや、この説明順の学習効果を示す比較ではありません。

課題

文の各位置の計算が前の位置を待つ方式と、位置同士を直接参照する方式を比べます。

並列に計算できる部分と依存する部分を区別する

RNN（再帰型ニューラルネットワーク）は、前の単語までに読み取った情報を、次の単語の計算に渡す仕組みです。そのため、ある位置の計算は前の位置の結果を待ちます。Self-attentionは、同じ層の位置同士を直接結びます。これは学習時の計算構造の違いで、文章を一度に生成するという意味ではありません。

計算例：KとVを別々に作ると何ができる？

2位置を [1, 0] と [1, 4] で表し、位置2を更新します。ここではQとKは入力の第1成分、Vは第2成分を取る線形変換です。マスクなし、1成分の1ヘッドだけを比べます。

  1. Q₂＝1、K₁＝1、K₂＝1。どちらも照合点は1なので、割合は1/2ずつです。
  2. 別の変換：V₁＝0、V₂＝4。割合は同じでも、出力に足す量は0と2です。合計は 1/2×0＋1/2×4＝2。
  3. Kと同じ変換をVにも使う：QとKを変えずに比べると、V₁＝V₂＝1。合計は 1/2×1＋1/2×1＝1。

この条件では、同じ変換に固定すると、同じKなら同じVになります。変換を分ければ、照合では同じとみなしても、混ぜる中身を変えられます。これは設計で何が可能になるかを示す例で、学習後に役割がどう分かれるかや、性能を測った結果ではありません。

候補が増えると、注意は広がる？

系列が長くなって増え得るのは、このQが照合する候補の数であって、QとKの成分数ではありません。成分数 dk は、同じモデルの同じヘッドでは変わりません。因果マスクで隠された未来位置の点数は、ソフトマックスの分母に入らないので、候補の追加には数えません。

同じ位置3のQと、元の点数 2、0、1 を固定します。最大の重みは約66.52%。点数 −2 の参照先を1つ足すと、最大は約65.72%。代わりに点数 4 の参照先を1つ足すと、新しい参照先が約83.10%を取ります。最大の重みで集中を見れば、候補を1つ増やすことで弱まる場合と、強まる場合があります。実モデルでは入力を変えると元の点数も変わり得ます。

平方根で割る理由は別です。 QとKの全成分を互いに独立な平均0・分散1の変数と仮定します。対応する一対の積も平均0・分散1で、それを dk 個足した内積の分散は dk。内積を √dk で割ると、その仮定の下で分散は1に戻ります。これは一組の照合点の話で、候補が増えたときの注意の配分を保証しません。原論文 §3.2.1

平均で失う区別を、連結で残す

1つのHeadは、1つのQueryに対して1組の参照割合を作り、その割合でVを混ぜます。複数Headは別々の変換を使うため、同じ入力から違う参照割合や内容の変換を作れます。すぐ平均すると、どのHeadから来た値かを区別できなくなる場合があります。連結（concat）は各Headの結果を別々の成分として残す操作です。

例えばH1=[2,0]、H2=[0,2]と、それを交換したH1=[0,2]、H2=[2,0]は、どちらも平均が[1,1]です。一方、連結は[2,0,0,2]と[0,2,2,0]で異なります。平均にした後では、後段の計算はこの2例を区別できません。

連結した行ベクトルをcとすると、出力はcWᴼです。Wᴼは「各Headのどの成分を何倍して足すか」を学習する設定です。例えばWᴼ=[[1,0],[0,0],[0,0],[0,1]]なら、H1の第1成分とH2の第2成分を選び、上の2例を[2,2]と[0,0]に分けられます。連結後の全ての区別がWᴼを通って残る保証はありませんが、平均に固定するより使い方を選べます。Headの文法・意味の担当を人が決めるわけではなく、Headの重複もあり得ます。これは区別を保持できる小例で、性能向上の証明ではありません。

なぜ位置が必要？ 3つの記号を逆順にする

順番を示す手がかりもマスクもなく、出力を各位置で同じ方法で読むエンコーダーを考えます。A B C を逆順の C B A にできたと仮定します。入力の先頭2つだけを入れ替えて B A C にすると、出力はどうなるでしょう。

  1. 入力と同じ入れ替えしか起きないので、元の出力 C B A の先頭2つが入れ替わり、B C A になります。
  2. でも B A C の正しい逆順は C A B。両方の入力を正しく逆順にすることは、この条件ではできません。

位置を足すと、移動した B の入力は B の埋め込み＋PE₂ から、同じ埋め込み＋PE₁ に変わります（PEᵢ は左から i 番目の位置ベクトル）。そこで WQ・WK・WV を掛けるので、位置の違いを照合側のQとKにも、混ぜる側のVにも渡せます。逆順を学べる保証ではありません。論文の位置加算を説明するための例です。

同じトークンの埋め込みe=[1,0]を2位置に置きます。位置を足さなければ両方[1,0]。説明用のp₀=[0,1]、p₁=[1,0]を足すと[1,1]と[2,0]になります。WQ=[[1,1],[0,1]]ならQは[1,2]と[2,2]です。このWQでは位置だけの変更でもQに差を渡せました。ただし別の変換で差が消えることもあり、位置を足せば必ず異なるQになるわけではありません。加算なので成分数は2のままです。

このp₀とp₁は加算用の手作り値で、原論文のsin/cos値ではありません。下のsin/cosは位置ごとに違うベクトルを規則で作る一方式です。sinとcosは角度に応じて−1から1を繰り返す波で、ペアは同じ速さで変化する2成分、ペアごとに変化の速さが違います。角度の単位はラジアンです。波の計算を未習でも、上の加算とQへのつながりから位置情報の役割を確かめられます。

なぜsinとcosをペアにする？

同じ速さのsinとcosを組にすると、位置の移動を円の上の回転として表せます。位置0→2と10→12では出発点が違いますが、どちらも2つ進むので、同じ角度だけ回します。ペアが違えば回る速さも違います。

式で確かめる：今のペアを [s, c] とし、s＝sin θ、c＝cos θ とします。進んだ分の角度を α とすると、移動後は [s cos α＋c sin α, c cos α−s sin α]。αが同じなら、掛ける係数は出発点θによらず同じです。

最初のペアでは、2つ進む角度は2ラジアン。位置ベクトルのこのペアだけの内積は、0と2でも、10と12でも、10と8でも cos 2≈−0.416 です。つまりこの内積だけでは進む向きまでは区別できません。実際のモデルは単語の表現を足し、別々の変換でQとKを作るため、この内積がそのまま注意の点数になるわけではありません。

比較条件：位置0 → 10 → 40。8成分の最初と最後のsin/cosペア。

位置0では[0,1,0,1,0,1,0,1]です。最初のペアは位置10で約[−0.544,−0.839]、位置40で約[0.745,−0.667]。最後のペアは位置40でも約[0.040,0.999]で、ゆっくり変わります。表示の1は丸め値です。位置符号はトークン表現へ成分ごとに足し、後ろに連結するものではありません。

学習と生成の流れを見る

入力と出力をつなぐ

入力文を読むEncoderと、訳の続きを予測するDecoderをつなぎます。cross-attentionのQはDecoder、K・VはEncoderから。出力の語彙確率が次の生成へつながります。

Encoder、Decoder、学習時の並列計算、逐次生成を区別する

Encoderは入力文の各トークンを、文脈を含むベクトルに変えます。Decoderはその情報と、すでに分かっている出力から次のトークンを予測します。Encoderを参照するAttentionでは、Decoder側からQuery、Encoderの出力からKeyとValueを作ります。学習時は正解をずらした入力があるため、マスクを使って複数位置を並列計算できます。生成時は、前に出したトークンが必要です。学習では、正解の翻訳を予測しやすくするよう、埋め込みや投影行列などのパラメータを更新します。

混合した表現は、そのまま単語になるのか

Attentionの重みは参照位置を選ぶ割合であり、出力トークンの確率ではありません。混ぜたベクトルは、まだその位置の表現です。Multi-headの連結とWᴼによる出力投影の後も、残差・正規化・FFNなどを通り、Decoderの最後で語彙候補の点数へ変換します。

残差加算の小例：副層への入力x=[1,0]、出力投影後のAttentionの結果a=[−0.2,0.6]なら、x+a=[0.8,0.6]です。元の表現を残しながら今回の処理結果を足します。原論文型のpost-LNでは、この加算の後にLayerNormを置きます。

つながりを最後まで追うため、ここだけ2成分・1位置の手作り計算を続けます。LayerNormの倍率γ=1、ずれβ=0、ε=0とする説明用条件では、[0.8,0.6]の平均0.7を引き、標準偏差0.1で割って[1,−1]になります。実装では安定化のためεを入れるので完全に同じ値とは限りません。この例は分散が0ではなく、dropoutも省いています。

FFNは各位置に同じ変換を別々に適用します。説明用に2つの行列を単位行列、バイアスを0とすると、ReLUが負の成分を0にしてFFN([1,−1])=[1,0]。FFNの残差は[1,−1]+[1,0]=[2,−1]、同じ条件で再びLayerNormすると[1,−1]です。ここで他位置を直接混ぜるのはFFNではありません。位置間を混ぜるAttentionと、各位置の成分を変換するFFNの役割が違います。原論文のFFNは中間次元を大きくします。この2成分の例はその幅を再現していません。

この[1,−1]が最終Decoder表現だったと仮定し、語彙用の行列を[[1,0,0],[0,1,0]]、バイアスを0とすると、3語の点数は[1,−1,0]です。指数にして合計で割ると、語彙確率は約[0.665,0.090,0.245]。これは3つの語彙候補の確率で、前のAttentionの参照割合の転用ではありません。表示は丸め値です。この例は接続を見るための一部分であり、Decoderのmasked self-attention・cross-attentionや複数層の全計算を実行したものではありません。

解答と理由・自己点検

設定Wと途中結果、損失と更新をつなぐ

Wは入力が変わっても使い続ける変換の設定です。Q・K・Vと注意の割合は、今回の入力と設定から計算する途中結果です。学習では最後の語彙予測を正解と比べ、誤りを表す損失が小さくなるようにWなどの設定を変えます。「どこを何％見るべきか」を注意割合の正解として直接教えるとは限りません。語彙予測からAttentionまでの計算のつながりを逆にたどって、設定への影響を求めます。

更新の意味だけを取り出した1変数の小例です。入力x=1、設定w=1、途中結果y=xw=1、目標t=0.8とします。損失L=(y−t)²/2=0.02。ずれを2乗すると正負の誤りを正の数で測れます。w=1.01ならy=1.01でL=0.02205、w=0.99ならL=0.01805です。この近所ではwを増やすと悪化し、減らすと改善します。

勾配は「設定値を少し増やしたとき、損失がどちらへ、どの程度変わるか」を表す数です。この小例のw=1での勾配は+0.2です（Lの変化は、小さなwの変化の約0.2倍）。学習率0.1のSGDは勾配の反対向きへ動かし、wを1−0.1×0.2=0.98へ更新します。途中結果を計算し直すとy=0.98、L=0.0162です。減ったのはこの例で確かめた結果であり、大きな更新や他の例でも改善する保証はありません。

この二乗誤差とSGDは、更新を理解するための補助例であり、Q/K/V全体の逆伝播でも原論文のAdamでもありません。語彙予測では、例えば正解に割り当てた確率pを使う損失−log(p)を考えます。logは自然対数で、pが1に近いほどこの損失は0に近づきます。p=0.46では約0.777、p=0.80では約0.223。1位になっただけでは十分とは限りません。これはラベル平滑化を省いた説明で、原論文の学習条件と同一ではありません。実モデルでは多数の設定を更新します。後の詳細な逆伝播では語彙予測からWQ・WK・WVまで具体的にたどります。

損失から、Qを作る設定はどう変わる？

説明用に、入力は1、学習する設定は w だけとし、Q＝1×w。参照先2つのKは0と1、Vは0と4に固定します。内積の点数は順に0とwです。

  1. まず予測：w＝0なら注意は半々。出力 y＝0.5×0＋0.5×4＝2。目標を3とする二乗損失 (y−3)²÷2 は0.500です。
  2. どちらへ変える？ w を少し増やすとK＝1の点数だけが上がります。V＝4が混ざる割合が増え、出力は3に近づきます。w＝0での勾配は−1。学習率0.1なら、勾配の反対向きへ0.1だけ動きます。
  3. 計算し直す：w＝0.1で点数は0と0.1。後者の割合は約52.50%、出力は約2.100。損失は0.500から約0.405に下がります。

勾配を自分で確かめる： w＝−0.01では損失が約0.51005、＋0.01では約0.49005。差を0.02で割ると約−1です。設定を増やす向きで、損失がどれだけ下がるかの近似です。

反例： V₁＝V₂＝2なら、w を変えて注意の割合が変わっても、出力は常に2。損失は変わりません。この経路だけでは、Qの設定をどちらへ変えるべきかという信号はありません。

注意の割合に正解を与えなくても、出力に影響すれば損失から設定へ情報が戻ります。これは経路を切り出した小例であり、語彙予測や原論文の学習を再現したものではありません。

何が難しかった？

翻訳では、離れた単語どうしの関係も必要です。従来のRNN（再帰型ニューラルネットワーク）は、文を先頭から順番に読み、それまでの情報を次の単語の計算へ渡します。このため、訓練時にも前の計算結果を待つ必要がありました。

何を変えた？

Transformerは、系列を処理する中心を再帰・畳み込みからAttentionへ変えます。入力文を読むEncoderと、訳の続きを作るDecoderを組み合わせます。Attentionは、各位置が参照する情報の割合を計算して混ぜる仕組みです。それだけで完結せず、順番を伝える位置表現、各位置の特徴を変換するFFN、元の表現を足す残差接続、数値のばらつきを整える正規化、次の単語の確率を出す出力層も使います。

Q・K・Vは、前提で見た行列の掛け算を使い、各位置の表現に役割ごとの行列を掛けて作ります。実モデルでは、変換に使う行列の値を学習で調整します。自己注意では、同じ系列の表現から、役割ごとに別の変換でQ・K・Vを作ります。Encoderの出力をDecoderが参照するcross-attentionでは、QはDecoder側の表現から、K・VはEncoderの出力から作ります。

g_s  = [−0.167808, 0.167808]

内積sⱼ=q₂·kⱼ/√2まで戻すと、QとKの勾配が出ます。

g_q₂ = (g_s₁ k₁ + g_s₂ k₂) / √2 = [−0.059329, 0.047463]
g_k₁ = g_s₁ q₂ / √2              = [−0.053396, −0.041530]
g_k₂ = g_s₂ q₂ / √2              = [ 0.053396,  0.041530]

1つの予測の損失から、両方の入力位置のK・Vに勾配が戻りました。 q₁は今回の損失の計算に使わないのでg_q₁=[0,0]です。これはこの1段の計算グラフについての話であり、多層モデル全体の他の経路まで0だという意味ではありません。

更新するのは中間値Q/K/Vではなく、共有するW

Q=XWQなどをさらに戻します。同じWを各入力位置で使っているので、Wへの寄与は位置ごとに足されます。

g_WQ = Xᵀ g_Q = [[−0.029665,  0.023732],
                  [−0.059329,  0.047463]]
g_WK = Xᵀ g_K = [[−0.026698, −0.020765],
                  [ 0.053396,  0.041530]]
g_WV = Xᵀ g_V = [[−0.280329,  0.339862],
                  [−0.179474,  0.217588]]

例えば、g_WVの左上は1×g_v₁の第1成分＋0.5×g_v₂の第1成分です。

ここまでが勾配の計算です。続いてSGDを1回だけ行います。学習率η=0.1で、W′=W−ηg_Wです。原論文のAdamを再現した更新ではありません。

WQ′ = [[ 0.502966, −0.102373],
       [ 0.205933,  0.395254]]
WK′ = [[ 0.402670,  0.202077],
       [−0.305340,  0.495847]]
WV′ = [[ 1.028033, −0.533986],
       [ 0.217947,  0.978241]]

XとRをそのままにして再計算すると、p丙は0.459642→0.472821、Lは0.777307→0.749038になります。これはこの数値と学習率での1回の結果です。任意の更新で必ず損失が下がること、他の例への汎化、教材の学習効果は示していません。

q₁の勾配は0でしたが、共有するWQが変わるため、再計算したq₁も変わります。Q/K/Vへ直接SGDをかけることと、Wを更新してQ/K/Vを再計算することは違います。

入力まで戻せばg_X=g_Q WQᵀ+g_K WKᵀ+g_V WVᵀも得られます。ただし、この例はXを固定しているので更新しません。別の構成でXを学習する埋め込みから作るなら、その埋め込み計算にも連鎖律を適用します。同じ語の埋め込みを複数位置で共有すれば、その寄与も足されます。本コードには埋め込み表の更新はありません。

勾配が出ない境界もある

  • 可視Keyが1個だけ：配分は必ず[1]なので、このAttention枝のscore・Q・Kへの勾配は0です。Vへの勾配は残り得ます。入力1トークンでも学習例は作れますが、この枝で配分の選び方を学ぶ余地はありません。
  • 可視Vがすべて同じ：配分を変えてもcが変わらないので、scoreへの勾配は0です。Vへの勾配まで0とは限りません。
  • softmaxの入力勾配の和は0：この例ではΣg_s=0、Σg_z≈0です。全入力へ同じ定数を足してもsoftmaxの出力が変わらないことに対応します。すべての勾配の和が0という意味ではありません。

範囲と出典

Attentionの式、学習する投影、因果マスク、語彙softmaxは原論文の§3.2・§3.4に対応します。数値・逆伝播の展開・固定R・1回のSGDは教材独自の数学補足です。原論文の§5.3・§5.4はAdamとlabel smoothingを使いますが、この例はSGDとone-hotの交差エントロピーを使います。

Transformer全体を実装していません。残差接続、LayerNorm、FFN、複数Head、Wᴼ、位置符号を作る処理、dropout、複数層、バッチ学習を省いています。検証したのは限定した計算と勾配の整合性です。実画面・実機・実聴・学習効果は未検証で、既存教材の評価点には加算しません。

最後の確認：注意の計算を、翻訳の1ステップにつなぐ

全文が届いてから訳す、1から数える例です。原文側は S1・S2・S3・PAD、訓練時の訳文側の入力は「開始・A・B」。位置2の入力Aから、次のBを予測します。記号は説明用で、実際の翻訳結果ではありません。

  1. この位置で、マスク付き自己注意とクロスアテンションは、どちら側からQ・K・Vを作りますか。それぞれ参照できる位置はどれですか。
  2. クロスアテンションの1ヘッドだけを計算します。位置2のQ＝1、原文側の各K＝1、1、0、9、各V＝0、4、5、99。すべて1成分です。参照できる位置の照合点、割合、割合×V、合計を順に求めます。
  3. この合計だけで、Bを出す確率は分かりますか。語彙の確率と注意の割合は、何を対象とした値ですか。
答えと自己採点
  1. マスク付き自己注意はすべて訳文側。Qは位置2から、参照先は開始・Aまでです。クロスアテンションではQを直前の自己注意を経た訳文の位置2の表現から、KとVをエンコーダーが作った原文側の表現から作ります。S1・S2・S3を参照し、PADを除きます。2種類のQは同じ位置に対応しますが、入力する中間表現も変換行列も別です。
  2. 参照できる点数は1、1、0。分母を Z＝2e＋1 とすると、原文4位置の割合は e/Z、e/Z、1/Z、0。割合×Vは 0、4e/Z、5/Z、0。合計は (4e＋5)/Z ≈ 2.466 です。PADの点数9を分母に入れません。
  3. この値だけでは分かりません。合計は1ヘッドがその位置に返す中間表現です。注意の割合は参照先の位置で合計1、出力側は最後の表現から語彙の各候補の点数を出し、そこで別に確率を計算します。

自己採点：①Q・K・Vの出どころ、②両方の参照集合、③候補ごとの点数・分母・正規化した割合、④同じ位置のVへの掛け算と合計、⑤注意の出力と語彙の確率の区別に、各1点。

  • ①②を間違えた → どこからQとK・Vを作り、どこを隠すか
  • ③④を間違えた → 整数の計算表で、照合点から同じ位置のVまで
  • ⑤を間違えた → 注意の割合と語彙確率では、何を数えるか
