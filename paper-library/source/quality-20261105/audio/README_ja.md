# HOME 音源そのものの改良試作

## 今回変えたもの

曲順やクロスフェードではなく、音を作る素材を変えた2曲の有限な試作です。公開中の v103、50曲バンク、音声プレーヤーには一切反映していません。

- 002「余白の朝」: 34秒。元の56音のピッチと開始時刻を保ち、実録音のピアノで再制作。
- 069「問いの余白」: 26.5秒。元の40音のピッチと開始時刻を保ち、同じピアノ素材で再制作。
- 元の単純なサイン波/FM合成、合成パッド、6本の固定ディレイは使っていません。
- 実際のピアノのアタック、倍音、自然減衰、ステレオ収録を使用。和音が次の和声まで過剰に残らないよう、鍵盤を離す時刻と余韻を調整しました。
- 伴奏を控え、旋律を前に置いたピアノ編成です。元の複数楽器をそのまま高級化したものではありません。
- 低域の機械的な振動を32 Hzのハイパスで抑え、強いリミッター・人工残響・不要な音圧上げは加えていません。

## 素材と利用条件

Versilian Community Sample Library の実録音 Steinway B ピアノ、CC0 1.0 Universal。13音、約49.1 MiBのWAVだけを取得しました。出版社は商用ソフトウェア、生成音楽、サンプラーでの利用を明記しています。別途の料金・アカウント・生成サービスは使っていません。

- 出版社: https://versilian-studios.com/vcsl/
- 公開リポジトリ: https://github.com/sgossner/VCSL
- ライセンス: https://github.com/sgossner/VCSL/blob/master/LICENSE
- 保存済みライセンス: VCSL_LICENSE
- 取得元URL、ファイルサイズ、SHA256: samples_manifest.json

録音は44.1 kHz / 24-bit / stereo。C2〜C6を4半音おきに使い、最も近い録音からの移調を最大2半音に制限しました。C4の実測基本周波数は約262 Hzで、ファイル名の音名と科学的ピッチ表記の整合を確認しています。サンプルレートを上げただけの改善ではありません。

## 出力

- renders/*_acoustic_piano_study.mp3: 試聴しやすい256 kbps版。
- renders/*_acoustic_piano_study.flac: 44.1 kHz / 24-bitのロスレスマスター。
- renders/*_before_matched_18s.mp3 と *_after_matched_18s.mp3: 元音源と新音源の同じ18秒区間。両方を−20 LUFSに揃えています。

最終出力の全編デコード、有限値、クリップなしを確認。002は−18.6 LUFS / 約−2.0 dBTP、069は−18.0 LUFS / 約−3.2 dBTPでした。詳細は render_results.json に保存しています。

## 残る限界

この環境では音声入力が非対応で、実際に聴いて美しさや不自然さを評価できません。音響特性とデータの正常性を確認したのであり、「高音質になった」「音楽として採用できる」との聴感合格判定ではありません。原曲の作曲・和声・フレーズが十分良いかという問題も、実楽器化だけでは解決しません。

今回は単一の録音強度・round robinを使用する小さな素材試作です。録音のベロシティレイヤー全体や複数の同音テイクを使った本格的なサンプラーほど、演奏表現は豊かではありません。50曲への一括適用や新しい曲としての採用は行っていません。ブラウザ用cue編集・全曲クロスフェード検証も別途必要です。

## 再現

既存のPython/NumPy/SciPy/FFmpegだけを使用。download_samples.py は明記した13ファイルだけを取得し、render_piano.py は既存スコアJSONから2曲だけをレンダリングします。元のMP3・楽譜・v103は保持しています。

配布用ZIPには音源、楽譜、スクリプト、ライセンス、検査記録を含めます。49.1 MiBの原サンプルは重複梱包せず、再取得URLとハッシュを添えています。
